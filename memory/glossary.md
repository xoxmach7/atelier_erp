# Glossary — Atelier ERP

## Аббревиатуры и термины
| Термин | Значение | Контекст |
|--------|---------|---------|
| КП | Коммерческое предложение | Расчёт стоимости для клиента |
| АВР | Акт выполненных работ | Финальный документ при закрытии заказа |
| FSM | Finite State Machine | Машина состояний заказа |
| RBAC | Role-Based Access Control | Система прав по ролям |
| P0 | Блок безопасности | Роли, RBAC, настройки — выполнен |
| P1 | Блок надёжности | Нумерация, JWT, PostgreSQL — выполнен |
| P2 | Архитектурные улучшения | В работе |
| P3 | Низкий приоритет | Косметика, рефакторинг |
| seed_groups | management-команда | Создаёт канонические группы в БД |
| seed_pilot | management-команда | Создаёт тестовых пользователей |
| settings_test | test-settings файл | SQLite in-memory, без PostgreSQL |
| NumberSequence | модель Django | Атомарная нумерация заказов/КП |
| default deny | принцип безопасности | Нет роли → нет доступа |

## Роли (канонические имена групп Django)
| Роль | Описание |
|------|---------|
| Owner | Владелец/Администратор, полный доступ |
| Designer | Дизайнер/замерщик, создаёт замеры и КП |
| Warehouse | Склад, видит только задачи по материалам |
| Seamstress | Швейный цех, только производство |
| Installer | Монтаж, только монтажные задачи |

## Статусы заказа (FSM)
| Статус | Значение |
|--------|---------|
| new | Новый заказ |
| in_work | Принят в работу (КП согласовано) |
| in_production | В производстве |
| ready | Готов к выдаче/монтажу |
| on_installation | На монтаже |
| waiting_final_payment | Ожидает остаток оплаты |
| completed | Завершён |
| cancelled | Отменён |
